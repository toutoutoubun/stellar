## Pourquoi Stellar ?

La plupart des chercheurs jonglent entre 6 à 8 outils distincts : un pour les références, un autre pour les notes, un autre pour la rédaction, encore un autre pour l'analyse, et ainsi de suite. Chaque outil excelle dans un domaine. Aucun ne communique avec les autres.

**Stellar réunit tout au même endroit.** Articles, notes, citations, analyse et export — dans une seule application de bureau qui tourne sur votre machine.

Pas de dépendance au cloud. Pas d'IA qui décide à votre place. Pas d'abonnement qui grève votre budget.

Vos pensées vous appartiennent.

## Philosophie

Stellar est créé par [Shiosailearn](https://shiosailearn.com) — *des outils silencieux pour les individus autonomes.*

Nous suivons trois refus :

| | Refus | Pourquoi |
|---|-------|----------|
| 01 | **Nous n'accompagnons pas** | « Je marche avec toi » crée une pression à performer. Nous vous donnons l'outil et nous reculons. |
| 02 | **Nous ne soutenons pas** | « Pour votre bien » vous définit comme quelqu'un qui a besoin d'aide. Nous n'utilisons pas cette définition. |
| 03 | **Nous n'intégrons pas** | L'intégration avec d'autres outils vole votre temps. Vos données, votre workflow. |

### Sur l'IA

Stellar n'a aucune fonctionnalité d'IA. Ce n'est pas une limitation — c'est un choix de conception.

Votre recherche exige votre jugement. Une IA qui résume vos sources ou suggère vos arguments pense à votre place. Nous croyons que la friction de lire, coder, connecter et écrire *est* la recherche.

### Sur les données

Local d'abord, avec sauvegarde cloud. Vos données vivent sur votre machine en SQLite. Sauvegardez vers le service cloud de votre choix. Nous ne voyons jamais vos données, parce que nous ne les demandons jamais.

## À qui s'adresse Stellar ?

Stellar est conçu pour les **chercheurs en sciences humaines** — politologues, historiens, linguistes, sociologues — qui veulent un outil unique et silencieux qui respecte leur processus de réflexion.

Stellar vous plaira si :

- ✅ Vous en avez assez de jongler entre plusieurs outils distincts
- ✅ Vous voulez vos données sur votre machine, pas sur le serveur de quelqu'un d'autre
- ✅ Vous ne voulez pas qu'une IA rédige votre analyse
- ✅ Vous ne pouvez pas vous permettre un logiciel d'analyse qualitative commercial coûteux
- ✅ Vous voulez un outil qui fonctionne dans votre langue

Stellar n'est **pas** pour vous si :

- ❌ Vous avez besoin de collaboration en temps réel (Stellar est mono-utilisateur)
- ❌ Vous avez besoin de composition typographique avancée
- ❌ Vous voulez qu'une IA résume vos articles

## Contribuer

Stellar est sous licence MIT et ouvert aux contributions. Consultez [CONTRIBUTING.md](CONTRIBUTING.md) pour les directives.

```bash
# Cloner et exécuter
git clone https://github.com/toutoutoubun/stellar.git
cd stellar
npm install
npm run tauri dev
```

**Prérequis :** Node.js 22+, Rust 1.75+, dépendances Tauri spécifiques à la plateforme ([voir docs Tauri](https://v2.tauri.app/start/prerequisites/))
