## South African language support

Stellar is building support for South African languages, starting with isiZulu, isiXhosa, Sepedi, Setswana, and Sesotho.

We are looking for terminology reviewers from South African academic communities — people who can review a small set of research UI terms (~100–200 words) in their language. No prior software experience required.

If you work with South African languages in an academic context:

- Open an issue using the [Localization Request](https://github.com/toutoutoubun/stellar/issues/new/choose) template
- Or email [shiosaisazanami@gmail.com](mailto:shiosaisazanami@gmail.com)
- Or visit [shiosailearn.com/za](https://shiosailearn.com/za)
