# 16-bit Lolita French Girly Theme

`Sugar Chateau 16` is a visual-first Stellar theme add-on with patisserie pinks, pixel lace, ribbon-like controls, and sweet French girly typography.

## Install

1. Open Stellar.
2. Go to Settings > Add-ons/Plugins.
3. Choose Add from folder or Add from file.
4. Select this folder or `bit-lolita-french-girly-theme.stellar-plugin`.
5. Pick `Sugar Chateau 16` from the theme selector.

## Files

- `stellar-plugin.json`: add-on metadata.
- `index.js`: theme registration and CSS.

This package is intentionally decorative and does not add app features.
