# Retro Pop 60s Theme

Stellar theme add-on package.

## Install

1. Open Stellar.
2. Go to Settings > Add-ons/Plugins.
3. Choose "Add from folder" and select this folder.
4. Go to Settings > Appearance and choose "Atomic Diner 1966".

You can also install the packaged `retro-pop-60s-theme.stellar-plugin` file.
