# Zen Wabi-Sabi Grayscale Theme

`Sumi Stillness` is a minimal grayscale Stellar theme add-on inspired by Japanese zen, wabi-sabi, sumi ink, washi paper, and quiet negative space.

## Install

1. Open Stellar.
2. Go to Settings > Add-ons/Plugins.
3. Choose Add from folder or Add from file.
4. Select this folder or `zen-wabi-sabi-grayscale-theme.stellar-plugin`.
5. Pick `Sumi Stillness` from the theme selector.

## Files

- `stellar-plugin.json`: add-on metadata.
- `index.js`: theme registration and CSS.

This package is intentionally visual and does not add app features.
