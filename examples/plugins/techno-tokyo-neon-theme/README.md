# Techno Tokyo Neon Theme

`Shinjuku Circuit` is a visual-first Stellar theme add-on with neon cyan, magenta glow, blue-black panels, kanji signboards, luminous controls, and cyber-style nodes.

## Install

1. Open Stellar.
2. Go to Settings > Add-ons/Plugins.
3. Choose Add from folder or Add from file.
4. Select this folder or `techno-tokyo-neon-theme.stellar-plugin`.
5. Pick `Shinjuku Circuit` from the theme selector.

## Files

- `stellar-plugin.json`: add-on metadata.
- `index.js`: theme registration and CSS.

This package is intentionally visual and does not add app features.
