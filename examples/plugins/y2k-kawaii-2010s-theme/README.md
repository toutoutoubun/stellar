# Y2K Kawaii 2010s Theme

Stellar theme add-on package.

## Install

1. Open Stellar.
2. Go to Settings > Add-ons/Plugins.
3. Choose "Add from folder" and select this folder.
4. Go to Settings > Appearance and choose "Prism Heart 2012".

You can also install the packaged `y2k-kawaii-2010s-theme.stellar-plugin` file.
